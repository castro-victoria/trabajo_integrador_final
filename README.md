Trabajo Final Integrador - Che Bakery
Che Bakery es un sitio web que representa una pastelería ficticia especializada en la elaboración y venta de cookies.
La página web tiene como objetivo que se permita conocer la marca, visualizar sus productos y realizar pedidos mediante un formulario.
El sitio web cuenta con tres páginas:
Inicio (index.html): presenta la marca, un carrousel de imágenes, información sobre el emprendimiento y sus sucursales.
Productos (merch.html): muestra los productos con sus respectivas imágenes, descripción y precios.
Pedidos (pedir.html): contiene un formulario para ingresar datos del cliente, seleccionar sabores y cantidades, y visualizar un resumen del pedido.
